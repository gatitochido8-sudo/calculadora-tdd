# Calculadora científica con TDD

Proyecto académico de Calidad del Software.

## Descripción

Esta aplicación implementa una calculadora científica utilizando la metodología TDD.

## Funcionalidades

- Suma de números reales
- Resta de números reales
- Multiplicación de números reales
- División de números reales
- Raíz cuadrada mediante el método Newton-Raphson
- Función exponencial mediante serie de Taylor
